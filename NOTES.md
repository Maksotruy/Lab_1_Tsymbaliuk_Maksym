# Робочі нотатки

Для `HomeScore` та `AwayScore` обрано тип `int`, оскільки кількість голів є цілим невід'ємним числом.

Для `MatchDate` обрано `DateOnly`, оскільки для обліку матчу потрібна саме дата проведення без часу.

Для `Stadium` використано `string?`, оскільки інформація про стадіон може бути відсутньою.

Для `Status` використано `enum MatchStatus`, оскільки статус матчу має обмежений набір можливих значень: запланований, завершений або скасований.
## Entity Framework Core та SQLite

Для роботи з базою даних використано Entity Framework Core та SQLite.

Створено контекст `FootballMatchesContext`, який містить `DbSet<FootballMatch> FootballMatches`.

Для підключення SQLite використано базу даних `footballmatches.db`.

Створено першу міграцію `Init` та застосовано її до бази даних за допомогою команд `dotnet ef migrations add Init` і `dotnet ef database update`.

У поточній моделі немає властивостей типу `decimal`, тому додаткове перетворення типів для SQLite не потрібне. Таке перетворення могло б знадобитися, якби модель містила десяткові значення типу `decimal`, наприклад ціну або іншу грошову величину.
