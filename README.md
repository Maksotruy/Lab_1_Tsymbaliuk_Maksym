# FootballMatches

## Тема

Облік футбольних матчів: команди, гравці, матчі; результати, голи, статистика та динаміка за періодами.

## Опис

FootballMatches — вебзастосунок для обліку футбольних матчів.
Застосунок призначений для зберігання та перегляду інформації про проведені та заплановані матчі.
